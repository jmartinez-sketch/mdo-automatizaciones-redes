Titular de marca: Chivo, tracking negativo, line-height 1.1.

```jsx
<Display level={1}>Sistema de marca</Display>
<Display level={2}>Los cinco colores del manual</Display>
<Display level={1} onInverse style={{ fontSize: 40 }}>Ordena hoy para crecer manana</Display>
```

En placas de redes el cuerpo se calcula segun el largo del texto (ver `fitSize` en el UI kit de redes) y se pasa por `style.fontSize`.
