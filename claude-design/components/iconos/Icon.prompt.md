Set completo de iconos de MDO: nueve glifos line-style, trazo 1.7.

```jsx
<Icon name="documento" size={34} style={{ color: 'var(--navy)' }} />
```

- Nombres: reloj, grafico, escudo, documento, calculadora, balanza, equipo, buscar, tilde.
- Toman `currentColor`: el color se hereda del contenedor.
- Se usan sueltos a 30-38px, dentro de un circulo de 86px con fondo `--grey`, o en un cuadrado de 62px con radio 14.
- No hay libreria de iconos ni emoji en la marca. Si falta un glifo, se dibuja con el mismo trazo (1.7, puntas y uniones redondeadas) y se agrega a este archivo.
